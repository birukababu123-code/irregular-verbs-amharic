IRREGULAR VERBS AMHARIC WEB APP

Contents: index.html, manifest.webmanifest, sw.js, icon.svg

QUICK TEST:
- Open index.html in Chrome to use the verb list, search and print.
- Browser installation and service-worker features require the files to be hosted on an HTTPS website (for example GitHub Pages).

INSTALL ON ANDROID AFTER HOSTING:
1. Open the HTTPS website in Chrome.
2. Tap the three-dot menu > Add to Home screen (or Install app if shown).
3. Notifications require permission. Web apps cannot reliably schedule exact daily notifications while closed on every Android/browser setup; for guaranteed daily reminders, use your phone's Clock/Reminder app.

This ZIP is a web app package, NOT an APK. It cannot be installed by tapping the ZIP file.
